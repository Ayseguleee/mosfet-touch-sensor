# MOSFET-Based Touch Sensor PCB Design

This project demonstrates the design, simulation, and PCB implementation of a high-sensitivity capacitive touch sensor circuit using power MOSFET switching principles.

---

### 📌 Project Overview
- **Objective:** Design an analog touch-sensing trigger mechanism to switch loads without mechanical components.
- **Tools Used:** Altium Designer (Schematic & Layout), Proteus (Circuit Simulation).
- **Hardware:** MOSFET (N-Channel), Passive Biasing Components, Touch Electrode.

---

### ⚙️ Technical Highlights
- **High Input Impedance:** Utilized MOSFET gate characteristics for reliable micro-current triggering.
- **Simulation:** Verified transient response and switching thresholds in Proteus prior to layout.
- **PCB Design:** Created custom footprints and optimized single-layer trace routing for noise immunity.
